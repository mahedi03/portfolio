3️⃣ Entity Relationship Map
Do not simply list entities. Map how they connect to each other.
•	For each major entity, identify what it depends on, what it affects, and what it leads to
•	Show at least 2 entity chains relevant to this article
•	Format: Entity A → Entity B → Entity C (relationship direction)
•	These chains should inform how sections are structured and in what order concepts are introduced
Example for iPhone repair:
Touchscreen Digitizer → OLED Display → Screen Assembly → Face ID Sensor
Cracked Glass → Moisture Entry → Internal Components → Battery Damage
💡  Entity chains increase topical authority and help AI systems understand the article as a knowledge graph, not just a list of terms.

Stat / Number Opportunity Flag
For each H2, note whether the section warrants a quantified claim (a specific number, percentage, or range) rather than a vague qualifier like "many" or "often."

💡  This closes the gap between the writing prompt's Hard Numbers Rule and the outline stage — without this flag, the writer has no signal for where a stat belongs.

NEW ADDITION — v2.1
Front-Loading Directive
Roughly 44% of AI-cited content is pulled from the first third of a page — the Introduction and Quick Answer sections carry the highest citation value on the page.
✅  Confirm the Quick Answer / definition section is planned as the single most information-dense, citable section — not just chronologically first
✅  Do not let the outline push the strongest fact, definition, or stat into a later section for narrative flow — flag it for placement in the first third
NEW ADDITION — v2.2
Listicle / Format Priority Flag
LLMs prioritize listicles, tables, and clear comparisons over dense prose — research cited in the GEO source shows listicles receive roughly 25% more priority from AI systems.
✅  For each H2, flag the best format: prose / numbered list / bulleted list / table / comparison
✅  Default to list or table format whenever the section covers steps, options, causes, or comparisons — reserve prose for sections that are genuinely narrative or explanatory
✅  Do not force a list format onto a section that doesn't have discrete, parallel items — a forced list reads worse than clean prose and doesn't gain a real GEO benefit
5️⃣ Retrieval Blocks per H2
For each major H2 in the outline, flag whether a retrieval block is needed. A retrieval block is a 30–60 word standalone answer that:
•	Directly answers the section's primary question
•	Requires NO surrounding context to be understood
•	Uses subject + predicate structure — no vague openers
•	Can be independently extracted and cited by ChatGPT, Gemini, Perplexity, or Claude
For each flagged H2, provide:
•	The question the retrieval block answers
•	The type of answer format (definition / list / process / comparison / fact)
•	A 1-sentence direction for what the answer should state
💡  Previously this prompt only requested 2–4 article-level answer blocks. This upgrade requires section-level retrieval blocks, which is how modern AI search systems index and cite content.
